# 01. Как работает LLM: от текста до следующего токена

> Материалы будут добавлены.

**Что разбираем.** Tokenization, embeddings, self-attention, Q/K/V, causal mask, multi-head attention, residual stream. Общая схема Transformer block. Logits, softmax, авторегрессионная генерация, temperature, top-k/top-p. Что происходит между prompt и ответом. Первые способы оценки: loss, perplexity, accuracy, exact match и бенчмарки начала 2020-х.
