# Открытый набор: 15 вопросов по ТФКП

Реальные вопросы по учебнику Горяйнова и Половинкина «Лекции по ТФКП» (2025) с эталонными ответами. Используйте их для отладки своей системы.

- `questions.jsonl` — только вопросы и варианты ответа, в формате входа `predict.py`.
- `reference_answers_pages.jsonl` — правильные варианты, объяснения и страницы учебника с обоснованием.
- `pairs.jsonl` — вопросы вместе с ответами, типом вопроса и типичными ошибками.
- `source.json` — выходные данные учебника и SHA-256 PDF, по которому составлены вопросы.
- Читаемая версия с ответами — [`../tfkp_15_qa.md`](../tfkp_15_qa.md).

Ссылки в эталонах — номера страниц PDF (с 1), а не `block_id` корпуса. Поэтому F1 по ссылкам на этом наборе автоматически не посчитать: найденные блоки сверяйте со страницами вручную.

Вопросы 13–15 проверяют недоопределённость условий (правильный ответ — отказ), а не отсутствие темы в учебнике.
