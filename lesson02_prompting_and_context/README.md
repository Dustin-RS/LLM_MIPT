# 02. Промпты, reasoning и context engineering

> Материалы будут добавлены.

**Что разбираем.** System prompts, instruction hierarchy, few-shot, chain-of-thought, self-consistency. Постановка задачи, примеры, ограничения и формат ответа. Статический и динамический контекст. Как разделять инструкции и данные, собирать контекст под задачу и проверять, что изменение промпта действительно помогло.
